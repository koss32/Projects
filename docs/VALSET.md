# VALSET · Landingpage für ein Akrobatik- und Zirkusstudio

[Zur Projektübersicht](../README.md)

## Aufgabe

Ein eigenständiger Webauftritt für ein Studio in Solingen: Angebote kennenlernen, eine passende Gruppe auswählen und eine vorbereitete Anfrage über WhatsApp öffnen.

Dieses Repository ist ein eigener Landingpage-Prototyp. Es ist getrennt von der VALSET-Angebotssektion im AK-Löwen-Projekt.

## Umsetzung im privaten Repository

- Statische HTML-Seite ohne erforderlichen Build-Schritt und ohne Backend.
- CSS und JavaScript für Kursauswahl, Quiz und vorbereitete WhatsApp-Nachrichten.
- Deutsche Inhalte sowie russische und ukrainische Übersetzungen.
- Animationen mit lokal enthaltenen GSAP-, ScrollTrigger- und Lenis-Dateien.
- Lokal gespeicherte Schriftdateien und Bilder in mehreren Größen.
- Vercel-Konfiguration für Header und Asset-Caching.

## Ein konkretes technisches Beispiel

Die Anmeldung im Prototyp speichert keine Anfrage auf einem Server. Die Auswahl wird zu einer WhatsApp-Nachricht zusammengestellt, die der Besucher selbst senden kann. Dadurch lässt sich der Ablauf vom Kursinteresse zur Kontaktaufnahme ohne eigenes Formular-Backend zeigen.
